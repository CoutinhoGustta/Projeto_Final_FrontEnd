# Dicionário de Código — HTML_PAINEL

Arquivo: `html/pages/tecnico/painel.html`

Este documento apresenta os principais trechos do arquivo e os comentários que devem ser pesquisados no VS Code para localizar cada parte do código.

| O que você procura                               | O que pesquisar no VS Code |
| ------------------------------------------------ | -------------------------- |
| Estrutura principal do painel do técnico         | `PAINEL DO TÉCNICO`        |
| Cabeçalho do painel                              | `CABEÇALHO`                |
| Conteúdo principal do painel                     | `CONTEÚDO PRINCIPAL`       |
| Resumo dos atendimentos e indicadores            | `RESUMO DOS ATENDIMENTOS`  |
| Lista de ordens de serviço atribuídas ao técnico | `ORDENS DE SERVIÇO`        |
| Rodapé do painel                                 | `RODAPÉ`                   |

**Observação:** todos os termos da coluna de pesquisa correspondem exatamente aos comentários existentes no código. Utilize `Ctrl + F` no VS Code para localizar cada trecho.

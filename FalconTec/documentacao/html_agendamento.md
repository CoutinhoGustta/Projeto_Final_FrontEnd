# Dicionário de Código — HTML_AGENDAMENTO

Arquivo: `html/pages/usuario/agendamento.html`

Este documento apresenta os principais trechos do arquivo e os comentários que devem ser pesquisados no VS Code para localizar cada parte do código.

| O que você procura                             | O que pesquisar no VS Code   |
| ---------------------------------------------- | ---------------------------- |
| Cabeçalho e navegação da página                | `CABEÇALHO E NAVEGAÇÃO`      |
| Logotipo da empresa                            | `LOGOTIPO`                   |
| Menu principal de navegação                    | `MENU PRINCIPAL`             |
| Conteúdo principal da página                   | `CONTEÚDO PRINCIPAL`         |
| Apresentação e banner da página                | `APRESENTAÇÃO DA PÁGINA`     |
| Formulário de solicitação de atendimento       | `FORMULÁRIO DE AGENDAMENTO`  |
| Cabeçalho e título do formulário               | `CABEÇALHO DO FORMULÁRIO`    |
| Campos com os dados do cliente                 | `DADOS DO CLIENTE`           |
| Campos com os dados do equipamento             | `DADOS DO EQUIPAMENTO`       |
| Preferência de atendimento e data              | `PREFERÊNCIA DE ATENDIMENTO` |
| Botão e área de envio da solicitação           | `ENVIO DA SOLICITAÇÃO`       |
| Estrutura do rodapé                            | `RODAPÉ`                     |
| Identidade e apresentação da empresa no rodapé | `IDENTIDADE DA EMPRESA`      |
| Links de navegação do rodapé                   | `NAVEGAÇÃO`                  |
| Informações de contato da empresa              | `CONTATO`                    |
| Direitos autorais                              | `DIREITOS AUTORAIS`          |

**Observação:** todos os termos da coluna de pesquisa correspondem exatamente aos comentários existentes no código. Utilize `Ctrl + F` no VS Code para localizar cada trecho.

## 1. Serviços oferecidos

| O que localizar                | Comentário para pesquisar no código    |
| ------------------------------ | -------------------------------------- |
| Refrigeração residencial       | `SERVIÇO 02: REFRIGERAÇÃO RESIDENCIAL` |
| Ar-condicionado                | `SERVIÇO 03: AR-CONDICIONADO`          |
| Manutenção preventiva          | `SERVIÇO 04: MANUTENÇÃO PREVENTIVA`    |
| Chamada final para atendimento | `CHAMADA FINAL PARA ATENDIMENTO`       |

## 2. Detalhes dos serviços

| O que localizar        | Comentário para pesquisar no código |

**Observação:** Os comentários `IMAGEM DO SERVIÇO` e `INFORMAÇÕES DO SERVIÇO` aparecem duas vezes cada, pois identificam os elementos de diferentes seções de serviços.

# Dicionário de Código — HTML_ADMIN

Arquivo: `html/pages/tecnico/admin.html`

Este documento apresenta os principais trechos do arquivo e os comentários que devem ser pesquisados no VS Code para localizar cada parte do código.

| O que você procura                           | O que pesquisar no VS Code           |
| -------------------------------------------- | ------------------------------------ |
| Estrutura principal do painel administrativo | `PAINEL ADMINISTRATIVO`              |
| Cabeçalho do painel                          | `CABEÇALHO`                          |
| Conteúdo principal do painel                 | `CONTEÚDO PRINCIPAL`                 |
| Resumo dos indicadores administrativos       | `RESUMO`                             |
| Área de gerenciamento dos técnicos           | `GERENCIAMENTO DE TÉCNICOS`          |
| Formulário para cadastrar um técnico         | `FORMULÁRIO DE CADASTRO`             |
| Lista de técnicos cadastrados                | `LISTA DE TÉCNICOS`                  |
| Área de gerenciamento das ordens de serviço  | `GERENCIAMENTO DE ORDENS DE SERVIÇO` |
| Formulário para criar uma nova ordem         | `FORMULÁRIO DE NOVA ORDEM`           |
| Lista de ordens de serviço                   | `LISTA DE ORDENS`                    |
| Área de acompanhamento dos serviços          | `ACOMPANHAMENTO`                     |
| Rodapé do painel administrativo              | `RODAPÉ`                             |

**Observação:** todos os termos da coluna de pesquisa correspondem exatamente aos comentários existentes no código. Utilize `Ctrl + F` no VS Code para localizar cada trecho.

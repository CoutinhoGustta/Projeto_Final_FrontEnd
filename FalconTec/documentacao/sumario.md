# Documentação do Projeto — Falcontec Refrigeração

Esta pasta reúne os dicionários de código do projeto Falcontec Refrigeração. Cada documento apresenta os principais comentários existentes nos arquivos HTML, CSS e JavaScript, facilitando a localização e a compreensão de suas funcionalidades.

## Estrutura da documentação

### HTML — Estrutura das páginas

Documentos que ajudam a localizar os elementos e as seções de cada página do sistema.

| Arquivo               | Descrição                                |
| --------------------- | ---------------------------------------- |
| `HTML_INDEX.md`       | Página inicial do site                   |
| `HTML_SERVICOS.md`    | Página de apresentação dos serviços      |
| `HTML_AGENDAMENTO.md` | Formulário de solicitação de atendimento |
| `HTML_TECNICO.md`     | Tela de login dos técnicos               |
| `HTML_ADMIN.md`       | Painel administrativo                    |
| `HTML_PAINEL.md`      | Painel individual do técnico             |

### CSS — Estilização

| Arquivo  | Descrição                                                           |
| -------- | ------------------------------------------------------------------- |
| `CSS.md` | Organização dos estilos, componentes e elementos visuais do projeto |

### JavaScript — Funcionalidades

| Arquivo         | Descrição                                                                     |
| --------------- | ----------------------------------------------------------------------------- |
| `MAIN_JS.md`    | Funcionalidade do formulário de agendamento e integração com o WhatsApp       |
| `TECNICO_JS.md` | Login, gerenciamento de técnicos, ordens de serviço e painéis administrativos |

## Como utilizar

1. Abra o documento correspondente ao arquivo que deseja consultar.
2. Identifique o trecho de código que procura na coluna de pesquisa.
3. Abra o arquivo original no VS Code.
4. Utilize `Ctrl + F` e pesquise o comentário indicado.

**Observação:** os termos de pesquisa correspondem aos comentários existentes nos arquivos originais do projeto.
